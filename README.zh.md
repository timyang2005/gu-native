# MHGU 的 Android 与 PC 版

在自己的设备上原生游玩你自有的 Monster Hunter Generations Ultimate（MHGU，即《怪物猎人 世代 终极版》）副本：在 Android 上，
使用为手机设计的触屏操作；在 Windows PC 上，使用键盘鼠标或手柄。它不是模拟器：游戏的代码经过转译，可直接在你的
设备上运行。两者使用同一个游戏目录，该目录只需用你自己的游戏副本制作一次。

**本项目不包含任何游戏代码、游戏文件、ROM 或密钥。你需要自备游戏副本。**

使用 Claude Code（Opus 5.5）制作。许多决定由我本人做出，因为对于这类项目，AI 还不适合拥有最终决定权。

[阅读西班牙语版指南](README.es.md)

最新版本位于 [Releases](../../releases/latest)：Android 的 APK 和 PC 的 `MHGU-PC-<version>.zip`。
可在社区的 [Discord](https://discord.gg/sk5xEjEMwF) 与其他玩家交流并寻求帮助。

## <a id="android"></a>Android

### <a id="what-it-does"></a>功能说明

#### 狩猎用的触屏操作

- **移动：** 一个不跟随手指移动的固定摇杆。拖过其边缘即奔跑；拔出武器时此功能会关闭，以免在战斗中途跑开。向上滑到摇杆上方出现的小圆圈（带挂锁图标），圆圈会亮起，此时抬起拇指：奔跑会锁定，猎人继续向前跑，并由你通过镜头转向，直到你再次触摸摇杆或该圆圈、拔出武器或打开菜单。若希望改为仅在按住按钮时奔跑：在齿轮按钮下进入 **控制** → **屏幕按钮**，关闭 **摇杆奔跑**，攻击按钮上方会显示一个 **奔跑** 按钮
- **镜头：** 在屏幕上任意位置拖动即可转向，如同手机游戏。双击可回正
- **怪物锁定：** 轻点 **L** 旁的挂锁，或按住 **L**，镜头会持续转向怪物，直到你再次执行该操作，如同较新的《怪物猎人》作品和 MH4U 移植版那样。它会跟随游戏的目标镜头所选中的怪物；若未选中，则跟随最近的怪物。目标按钮（**ZL**，或你的 **控制类型** 所使用的按钮）可将其切换到另一只怪物。当游戏内的 **L/R 按键控制** 互换后，目标按钮与 **L** 对应的按钮也会像游戏本身那样互换：按钮上的角标会显示各自触发的是哪个键。自行转动镜头或按下 **L** 只会让它暂停片刻；它只跟随当前区域内的怪物。可在齿轮按钮下进入 **控制** → **锁定（按住 L）** 将其关闭
- **弓与弩的专属布局：** 在狩猎中手持弓或弩时，控制会自动变化：拇指下方有一个大号开火按钮、装填、轻点开镜或按住快速瞄准、蹲射，以及用于切换弹药的箭头（按住可连续切换）。按住开火按钮时在其上拖动即可瞄准。它遵循游戏的 **弓的控制** 选项，并在编辑器中拥有独立的位置
- **滑动切换弹药：** 除箭头外，也可在道具栏上向上或向下滑动。游戏的列表现在会完整显示，并列出每种弹药的名称
- **锁定怪物时射击：** 从通常架势射出的攻击会朝其身体中部飞去，即使它比你高或低。要让弹道抬高，弩会短暂进入快速瞄准。你自己的瞄准、蹲射以及各狩猎风格的招式仍由你控制；未锁定时，瞄准方式与平常一样
- **道具：** 道具栏位于底部中央。轻点使用道具，滑动切换道具；快速滑动不会再误用道具。将手指按住道具栏，可查看当前选中项之前和之后的道具，如同游戏中按住 L 时显示的那样：此时滑动可轮换，抬起手指则关闭且不使用任何道具。两侧的箭头也可切换（隐藏方法：齿轮按钮 → **控制** → **屏幕按钮** → **道具栏箭头**）。作为随从猫（Prowler）时，箭头和滑动切换的是支援动作
- **狩技：** 轻点每个狩技的面板即可使用。它会按下游戏 **控制类型** 中该狩技对应的按键（类型 1 到 4，以及 **L/R 按键控制** 和 **右摇杆控制**），连接手柄时同样有效
- **攻击：** 三种布局可选：斜向分割的长条、彼此独立的按钮，或屏幕角落里的 U 形带。开启 **滑动时保持防御**（位于 **屏幕按钮** 下）后，拇指从防御滑到攻击按钮上仍会保持防御，适用于长枪反击之类的动作
- **其他按钮：** 回避、防御与收刀，各有自己的图标

#### 菜单与舒适性

- **为拇指设计的菜单：** 打开游戏菜单时布局不会发生任何变化：会显示一个小摇杆并移动光标，翻页按钮位于其上方。移动摇杆仍可让猎人行走（在猎人无法行走的地方，例如城镇的道具箱或商店，它会移动光标；在游戏显示模型的地方，例如铁匠铺，摇杆和拖动会旋转模型，如同使用手柄）；A 和 B 保持在原位，在屏幕上拖动也可移动光标。该小摇杆可在编辑器中像其他按钮一样移动和调整大小。隐藏方法：齿轮按钮 → **控制** → **屏幕按钮** → **菜单摇杆**
- 手机键盘可用于输入角色名，也可在设置的文本输入框中输入（开启 **手机键盘**；Enter 确认，Back 隐藏键盘并保留已输入内容）；菜单自身的按键仍可供手柄使用
- 设置支持触屏操作，外观与游戏一致
- **更快的饮用与进食：** 两个可选作弊，默认关闭，位于齿轮按钮 → **作弊**。它们会将动画速度提高到 1.7 倍或 2.5 倍，但不会让你在饮用时行走
- **你自己的作弊与模组：** 见[作弊与模组](#cheats-and-mods)
- 从模拟器、其他设备或 PC 版导入存档，也可导出带走：见[存档](#saves)
- 离开应用时游戏会自动暂停；单人游玩时，设置打开期间也会暂停
- 按钮轻点时的振动，以及手机上的游戏震动，无论是否连接手柄

#### 自定义

- 按住齿轮按钮打开编辑器（或 **控制** → **自定义按键与 HUD**）：移动并调整每个按钮的大小，也可移动、调整或隐藏游戏 HUD 的每个部分：时钟、生命与耐力、锋利度与各种量表、队伍、地图、目标镜头、道具栏和狩技。在狩猎之外，边框会显示每个部分的位置及其名称。将某个部分放到按钮上时，该部分会变红，按钮也会变红；默认布局不会显示红色。道具栏无法在那里隐藏：它正是你用手指选择和使用道具的方式
- 编辑器面板会避开你正在放置的内容：拖动其标题（两端的把手）即可移动。轻点标题并用 - / + 或双指捏合可将其缩小，最小到 60%。它会保持你留下的位置和大小
- 移动过的部分会停留在你放置的位置：聊天行、弓或弩的瞄准以及任务完成印章不再被送回游戏原本的位置，打开游戏菜单时也不会跳动。若某个部分会压在该菜单窗口上，它会隐藏，直到菜单关闭
- 游戏 HUD 会重新排列，以避开你的拇指（**为触屏移动 HUD**）。关闭后，HUD 与使用手柄时相同。编辑器的 **HUD：手柄** 按钮会按照连接手柄时的布局排列 HUD，无需真的连接手柄；手柄的 B 会在不保存的情况下关闭编辑器
- 可调整控制透明度和镜头速度
- **屏幕按钮：** 在齿轮按钮下进入 **控制** → **屏幕按钮**，选择显示哪些按钮。你可以添加 L、ZL、ZR、-、方向键和摇杆按下，这些默认隐藏（打开游戏菜单时，方向键会让位给菜单摇杆）。在城镇中 ZL 始终显示，因为它会打开联机菜单。在游戏菜单中也可以添加 ZL 和 ZR（**菜单中的 ZL**、**菜单中的 ZR**），某些菜单用它们切换栏目或显示更多信息
- **组合按键：** 在同一页面中，最多可自定义 6 个按钮，每个按钮同时按下多个键，例如 A+X。用编辑器放置它们，也可以将它们映射到手柄按键上

#### 显示与性能

- 在性能强劲的手机上最高可达 120 fps，并可配置帧率上限
- 填满整个屏幕，从超宽屏手机到 4:3 掌机均可适配
- 可调整 3D 分辨率，最低 25%，以便在性能有限的设备上提升速度
- **阴影：** 关闭可提升速度，位于齿轮按钮 → **画面与音频** → **阴影**。在 Moto g06 上，狩猎时它让 GPU 每帧的工作量减少约 15%
- **低配模式：** 面向性能较弱的手机。它会关闭泛光、景深与阴影，使用更轻量的纹理，并在较小的 3D 画面上保持 HUD 清晰
- **烤面包机模式：** 低配模式的第三个选项，面向性能最弱的手机以及为省电而设：25% 的 3D 分辨率、30 fps、无混响和草地，HUD 与纹理也更轻量。在 Moto g06 上，它能保持 30 fps，耗电比 60 fps 的低配模式少约三分之一
- **泛光与景深** 以及 **混响**（齿轮按钮 → **画面与音频**）：各自独立的开关。关闭后，GPU 或处理器的工作量会减少
- **草地**（齿轮按钮 → **画面与音频**）：关闭后会省略地图中的高草与植被，在植被密集处速度提升更明显（例如沼泽地的 8 区）
- 可选的 FPS 与温度计数器
- 在配备 Mali GPU 的设备以及内存较小的手机上占用更少内存
- 屏幕刷新率会跟随你的 FPS 上限：在 60 fps 时以 60 Hz 运行，即使屏幕能到 120 Hz
- **如果手机发热，请降低 FPS 上限。** 没有比这更有效的方法：在 Galaxy S25 Ultra 上，从 120 降到 60 可少用四分之一到三分之一的电量；在 Moto g06 上，从 60 降到 30 可少用五分之一
- 在 Mali GPU 上，纹理会由多个核心解码，以减少卡顿
- **使用你自己的 GPU 驱动：** 仅限 Adreno，风险自负。在齿轮按钮下进入 **画面与音频** → **GPU 驱动**，添加一个包含 `meta.json` 和库文件的 .zip。默认使用系统驱动；如果某个驱动在启动时失败或无法加载，应用会自动回退到系统驱动并告知你
- **Adreno 修正：** 在采用 Vulkan 1.1 驱动的 Adreno 上，若 3D 分辨率较低，应用会保持 2x MSAA，以免画面呈网格状重复。如果画面偏暗或闪烁，或希望提升速度，可在齿轮按钮 → **画面与音频** 中将 **Adreno 修正** 设为 **关闭**

#### 使用手柄

- 连接手柄后触屏控制会立即隐藏，断开后恢复，无需重启
- 齿轮按钮会留在屏幕上，因此你始终可以打开设置。也可以同时按 **+** 和 **-**
- 按下右摇杆会锁定怪物（使用游戏的 **控制类型 3** 时，该键用于切换目标，此时改为按住）。锁定开启后，目标图标旁会显示挂锁，弩的射击会瞄准怪物身体，与触屏操作相同
- **任意手柄：** 如果游戏无法正确识别你的手柄，请进入齿轮按钮 → **控制** → **映射手柄**，依次按下每个按钮一次。映射会按该手柄型号保存。如果某个手柄必须先映射才能被识别，连接时应用会提示你

### <a id="how-well-does-it-run"></a>运行表现如何？

使用屏幕上的计数器测得。在「低配模式」一列中，3D 画面为 40%，且 FPS 上限已提高；唯一例外是 5 分钟测试，它使用该模式的 30 fps 上限：

| 设备 | 芯片 | GPU | 内存 | 普通模式 | 低配模式 |
|---|---|---|---|---|---|
| Galaxy S25 Ultra | Snapdragon 8 Elite | Adreno 830 | 12 GB | 120 fps | 村庄内 120 fps |
| Anbernic RG406V | Unisoc T820 | Mali-G57 | 8 GB | 全分辨率 48 fps，50% 时 60 fps | 60 fps |
| moto g06 power | MediaTek MT6769 | Mali-G52 MC2 | 4 GB | 全分辨率 16 fps，50% 时最高 28 fps | 45 fps；5 分钟测试中稳定 30 fps |

在 4 GB 内存的手机上，请先关闭其他应用：内存耗尽时 Android 可能会关闭游戏。若要提升速度，
请开启低配模式：进入齿轮按钮 → **画面与音频** → **低配模式**，保存并重启游戏。它会将 3D
分辨率设为 40%、上限设为 30 fps，两者均可更改。这会牺牲一些锐度：画面看起来会更柔和。

### <a id="what-you-need"></a>所需条件

- **一台 Android 设备：** Android 9 或更高版本（Android 9 为实验性支持：未能在该版本上测试）、64 位，并支持 Vulkan 1.2。近几年几乎任何设备都可以。Vulkan 1.1 可实验性运行。对于 2018 年以前的处理器，应用会在首次启动时适配游戏代码，这需要几秒钟。
- **约 13 GB 可用空间**（设备上）。
- **一台 Windows 或 Linux PC**，仅用于安装准备，需约 10 GB 可用空间。
- **你自己的游戏副本**，已更新到 1.4.0 版本。

### <a id="setup"></a>安装设置

共三步，只需做一次。

#### 第 1 步：获取游戏文件

你需要自己游戏中的两个文件夹：`exefs` 和 `romfs`。它们必须包含 1.4.0 更新。

如果你的游戏副本位于 PC 上的 Ryujinx 模拟器中：

1. 确保游戏已应用 1.4.0 更新。
2. 右键点击游戏，打开 **Extract Data**，先提取 **ExeFS**，再提取 **RomFS**，放入同一个空文件夹。

将两者放在同一个文件夹中，例如 `C:\MHGU`：

```
MHGU
├─ exefs
└─ romfs
```

本项目不说明如何从主机中导出游戏，也不提供游戏文件、密钥或其链接。

#### <a id="step-2-create-the-game-code"></a>第 2 步：生成游戏代码

应用本身不包含游戏代码，因此你需要从自己的游戏副本生成。它在你的 PC 上运行，不会向任何地方发送数据。

1. 安装 [Python](https://www.python.org/downloads/)。在 Windows 上，勾选安装程序中的 **Add python.exe to PATH**。
2. 在本页面点击绿色的 **Code** 按钮，再点击 **Download ZIP**，然后解压。
3. 打开解压后的文件夹，再进入其中的 `tools` 文件夹。
4. Windows：点击该窗口的地址栏，输入 `cmd` 并按 Enter。Linux：在该文件夹中打开终端。
5. 输入以下命令，将路径替换为你自己的文件夹，然后按 Enter：

   ```
   python build_game.py --android C:\MHGU
   ```

首次运行时，它会下载 Google 的 Android 编译器（约 1.8 GB）。之后它会自行工作：在较快的 PC 上约 6 分钟，
较慢的 PC 上更久。当它显示 **Done** 时，你的文件夹中会有两个新文件：

```
MHGU
├─ exefs
├─ romfs
├─ libmhgugame.so
└─ libmhgugame.id
```

**这些文件由你的游戏生成：请自行保留，不要分享。**

你也玩 PC 版吗？省略 `--android`：一次运行会同时生成两个平台的游戏代码，并额外生成 `mhgugame.dll` 和
`mhgugame.id`。它还会下载 llvm-mingw，即 PC 版游戏的编译器（约 150 MB），并多花几分钟。
再次运行会保留已生成且最新的内容。

#### 第 3 步：安装

1. 将整个 `MHGU` 文件夹复制到你的设备上，例如使用 USB 线。它可以放在设备存储或 SD 卡中的任何位置，
   但不能放在 `Android/data` 内。
2. 在设备上从 [Releases](../../releases/latest) 下载 APK 并打开。Android 可能会请求允许从浏览器安装
   应用。
3. 打开 **MHGU**，点击 **授予权限并选择文件夹**，在 Android 询问时开启文件访问权限。游戏只会读取该文件夹。
4. 找到你的 `MHGU` 文件夹（会显示 ✓），然后点击 **使用此文件夹**。应用有自带的文件夹浏览器；如果你更想用 Android 自带的，点击 **Android 选择器**。

应用会检查该文件夹，若有问题会准确告知缺少什么，然后启动游戏。

你的存档和设置会单独保存在 `Android/data/com.mhgu.recomp/files`。之后若要选择其他文件夹：齿轮
按钮 → **菜单选项** → **游戏目录**。

### <a id="saves"></a>存档

#### 导入存档

你可以从模拟器、其他设备或 PC 版导入存档：

1. 找到名为 `system` 的存档文件。在 Ryujinx 中：右键点击游戏，选择 **Open User Save Directory**。在 yuzu 中：右键点击游戏，
   选择 **Open Save Data Location**。从 PC 版导入：先在 PC 版中导出（见[PC 版存档](#saves-1)）。
2. 将该文件复制到你的设备上，例如 Downloads 文件夹。
3. 在游戏中进入齿轮按钮 → **菜单选项** → **导入存档**，然后选择该文件。

设备上的所有角色都会被替换，游戏会重启。你之前的存档会保留在
`Android/data/com.mhgu.recomp/files/MHGURecomp/save_backups`。

#### <a id="export-your-save"></a>导出存档

若要将存档带到模拟器、其他设备或 PC 版：

1. 先在游戏中保存。然后进入齿轮按钮 → **菜单选项** → **导出存档**，并选择一个文件夹。
2. 会在该处创建一个名为 `MHGU_save_...` 的文件夹，其中包含 `system` 和 `system_backup` 文件。将其移动到你的 PC。
3. 在 Ryujinx 中：右键点击游戏，选择 **Open User Save Directory**。在 yuzu 中：右键点击游戏，选择 **Open Save Data Location**。
4. 备份现有内容，然后将两个文件复制进去。

#### <a id="move-a-save-between-android-and-pc"></a>在 Android 与 PC 之间转移存档

两边使用相同的存档，因此可以双向转移：

- **从手机到 PC：** 在手机上选择 **导出存档**，将 `MHGU_save_...` 文件夹复制到 PC。在 PC 版中进入
  **F1** → **菜单选项** → **导入存档**，选择该文件夹中的 `system` 文件。
- **从 PC 到手机：** 在 PC 版中进入 **F1** → **菜单选项** → **导出存档**，将 `system` 文件复制到
  手机。在手机上选择 **导入存档** 并选择它。

导入会替换目标设备上的所有角色，被替换的存档会像上面那样保留一份副本。

#### 选择存档保存位置

除非你另选位置，否则存档保存在应用自己的文件夹中；你也可以选择同步应用（Syncthing、
FolderSync 等）与其他设备共享的文件夹。进入齿轮按钮 → **菜单选项** → **存档目录**，然后选择
文件夹：

- 存档会放在你所选文件夹内名为 `MHGU save` 的文件夹中，这样一个共享文件夹可以同时容纳 MHGU 和 MH4U for
  Android 的存档（`MH4U save`）。如果文件夹中已有存档，例如由 **导出存档** 创建的，则会按原样使用。
- 在任何更改发生前，存档会先复制到那里。如果该文件夹中已有存档，你可以选择保留哪一个；
  另一个会保留副本，存放在应用自己文件夹的 `save_backups` 中。
- 游戏会重启以使用该文件夹：请先保存。同一屏幕上的 **使用游戏自己的文件夹** 可返回原设置。
- 在两台设备上使用时，同一时间只在一台上游玩，并等待同步应用完成同步后，再在另一台上打开游戏。

游戏启动时会检查该文件夹。如果无法访问、文件夹为空但之前有存档、同步应用保留了两个
版本的存档，或另一台设备正打开游戏，它会说明情况并让你选择如何处理。如果保存时无法访问该文件夹，
该次存档会留在设备上，下次启动时会询问保留哪一个。

### <a id="cheats-and-mods"></a>作弊与模组

- **作弊：** Atmosphere 格式的 `.txt` 文件，适用于 1.4.0 版本（其构建 id 为 `FB08F1D20FD1204F`）。在齿轮按钮下进入 **作弊** → **添加作弊**，选择文件，然后在同一页面中逐项开启。它们默认关闭。
- **模组：** 包含 `romfs` 或 `exefs` 的模组文件夹，或该文件夹的 `.zip`。在齿轮按钮下进入 **模组** → **添加模组**。然后在页面中排序并开启。
- 你也可以自行将它们复制到游戏目录中，放在 `exefs` 和 `romfs` 旁边的 `cheats` 与 `mods` 文件夹内。游戏会在启动时读取它们。
- 修改游戏代码的作弊与模组可以使用，但游戏的该部分会运行得更慢。在线使用作弊时，只有在集会所内所有人都同意的情况下才可以。

### <a id="multiplayer"></a>联机

#### <a id="local-play"></a>本地游玩

同一 Wi-Fi 上的两台设备可以一起游玩：

1. 双方都进入城镇，点击 **ZL** 并选择 **连接**。
2. 一名玩家（主机）选择 **创建集会所**，并按 **X** 确认。
3. 另一名玩家选择 **搜索集会所**，然后选择该集会所。
4. 如果集会所未出现：进入齿轮按钮 → **联机** → **搜索主机**，输入主机的 IP 后再次搜索。

创建、发现并加入集会所已在 Motorola 和 Anbernic 设备上测试，但尚未完成一次完整任务。

#### <a id="over-the-internet"></a>通过互联网

应用已预设一个集会所服务器 `hunterhubid-gu-hub.duckdns.org`，由社区玩家运营（并非本项目）。同一服务器上的玩家可以互相发现集会所，无需开放端口。

1. 按[本地游玩](#local-play)的方式操作：一人创建集会所，其他人搜索。互联网上的集会所会与 Wi-Fi 本地集会所一起显示。
2. 若只想与好友游玩：在齿轮按钮 → **联机** 中，所有人输入相同的 **匹配码**。只有持有该匹配码的玩家才能看到你的集会所。
3. **集会所服务器** 可选择其他服务器：**自定义...** 可手动输入（名称或 IP；若不是 39510，还要加 `:port`；`server` 文件夹中的小程序可运行一个服务器，见 `server/README.md`），或选择 **关闭** 仅使用本地网络。**检查集会所服务器** 会显示它是否响应以及列出多少个集会所。
4. 你输入并保存的服务器和匹配码会保留在列表中，最近使用的在前（最多 24 个），以便再次选择；旁边的 **×** 可将其删除。

首次在线游玩时，会有提示说明游戏连接到哪个服务器：与互联网上的任何服务器一样，该服务器能看到你的 IP 地址。

不使用服务器时：将所有设备接入同一个 VPN（例如 Tailscale 或 ZeroTier），并在 **搜索主机** 中输入主机的 VPN IP。

0.1.6 或更高版本的手机与 PC 可以在同一集会所中相遇，无论通过服务器还是同一 Wi-Fi。已在 0.1.9 中测试：两部
手机通过默认服务器并使用匹配码进入同一集会所；一台 PC 通过服务器以及在同一 Wi-Fi 下加入手机的集会所；尚未共同完成一次完整任务。

#### 集会所中的怪物 HP 与村庄任务

可调整的怪物 HP（齿轮按钮 → **游戏玩法**）以及集会所中的村庄任务（齿轮按钮 → **联机**）来自 MHGURecomp，即本项目所基于的项目。它们尚未在 Android 上经过完整测试。

### <a id="update-to-a-new-version"></a>更新到新版本

1. 从 [Releases](../../releases/latest) 下载新 APK 并打开：它会覆盖安装现有应用。你的存档、
   设置、触屏布局和游戏目录都会保留。
2. 如果新版本需要新的游戏代码，应用启动时会显示「This libmhgugame.so is from another version」。请
   用新版本的工具重新执行第 2 步（再次使用本页的 ZIP，或该版本发布页上的 **Source code (zip)**），并将
   两个新文件复制到设备上的游戏目录。从 0.1.6 到 0.1.7，游戏代码保持不变。

### <a id="uninstall-it"></a>卸载

- 若想保留存档，请先导出：见[导出存档](#export-your-save)。
- 像卸载其他应用一样卸载。Android 可能会询问是否保留其数据（存档和设置）；如果不保留，这些数据
  会随应用一起删除。
- 你的游戏目录归你所有：可以留给 PC 版使用，也可以删除。你添加的作弊与模组就在其中。
- 在你用于安装制作的 PC 上，工具会将下载的编译器保存在用户文件夹的 `.mhgu-tool` 中。如果不再生成游戏代码，可以删除它。如果缺少 lz4 Python 包，工具会安装它（`pip uninstall lz4`
  可将其移除）；如果你为此安装了 Python，Python 会保留。

### <a id="samsung-game-booster"></a>Samsung：Game Booster

Samsung 的性能面板只会对它识别为游戏的应用程序显示，而手动安装的 APK 不被视为游戏。要获得
该面板，请通过 PC 使用 [adb](https://developer.android.com/tools/adb) 安装一次 APK：

```
adb install -r -i com.mhgu.recomp MHGU-0.1.7.apk
```

请使用你下载的 APK 文件名。这是可选项：不这样做游戏也能正常运行。若至少想在 Gaming Hub 中看到它：**我的游戏** → **游戏库** → 三个点 → **添加游戏**。

### <a id="if-something-goes-wrong"></a>出现问题怎么办

| 问题 | 处理方法 |
|---|---|
| `python` 无法识别 | 重新安装 Python，勾选 **Add python.exe to PATH**，并打开新的终端 |
| lz4 报错「Failed to build installable wheels」 | 从 0.1.9 起，当你的 Python 无法安装 lz4 时，工具会在没有 lz4 包的情况下读取游戏代码：请重新下载工具 |
| 「there is no exefs/main」 | 路径必须是包含 `exefs` 和 `romfs` 的文件夹 |
| 「This exefs is not version 1.4.0」 | 使用带 1.4.0 更新的 `exefs` |
| 「romfs is incomplete」 | 使用已应用更新的基础游戏 `romfs`。它包含 35,531 个文件 |
| 「libmhgugame.so is missing」 | 执行第 2 步，然后将两个新文件复制到设备上的文件夹 |
| 「This libmhgugame.so is from another version」 | 新的应用版本需要重新生成：用新下载的工具重复第 2 步 |
| 游戏文件界面显示「EACCES」或「open failed」 | 另一个应用（例如通过 Shizuku 的文件管理器）在 `Android/data` 中创建了应用的文件夹。从 0.1.9 起，应用会将其收回，或将文件保存在自己的私有文件夹中并说明 |
| 游戏自行关闭 | 关闭其他应用并降低 3D 分辨率。通常是内存不足 |
| 只有触屏按键、画面全黑，或按下 A 时关闭 | `romfs` 复制到设备的过程未完成。请重新复制，并检查其占用是否为 12.3 GB |
| 游戏显示 **Game files incomplete** | `romfs` 的部分文件在复制时被截断，游戏在读取这些文件时可能关闭或绘制成黑色。请重新复制 `romfs`，并检查其占用是否为 12.3 GB |
| 游玩几分钟后关闭 | 更新到 0.1.6 或更高版本：它在 PowerVR GPU 上以不同方式使用显存。如果仍然发生，请分享日志：日志每分钟记录一次内存 |
| 在性能较弱的手机上运行缓慢 | 开启低配模式，关闭 **阴影**，并尝试 33% 或 25% 的 3D 分辨率。仍然缓慢：低配模式 → **烤面包机** |

如果仍然失败，请在 [Discord](https://discord.gg/sk5xEjEMwF) 提问，或提交 [issue](../../issues)，并附上设备型号和日志。如果游戏因错误关闭，会有屏幕让你
分享日志；如果没有，可在齿轮按钮 → **菜单选项** → **分享日志** 中找到。如果屏幕一直黑屏且无法访问齿轮按钮，长按
应用图标也会提供 **分享日志**。请勿附加游戏文件。

## <a id="pc-windows"></a>PC（Windows）

同一个游戏目录可在 Windows PC 上运行：`MHGU.exe` 会原生运行你的游戏。

下载内容仅包含程序：游戏代码（`mhgugame.dll` 和 `mhgugame.id`）需用你自己的游戏副本制作一次，见
[安装设置第 2 步](#step-2-create-the-game-code-1)。

### <a id="what-it-does-1"></a>功能说明

#### 键盘与鼠标

- **仅用键盘和鼠标即可游玩：** WASD 移动，鼠标转动镜头，左键攻击（X），F 为动作键（A）：用于对话、打开、采集和拾取。完整列表见[控制](#controls)
- **右键是第二种攻击（A），仅在拔出武器时有效：** 它绝不会误触发对话、打开或采集
- **每个按键都可以更改，** 每个按钮最多两个键，包括鼠标按键：**F1** → **控制** → **按键绑定**。镜头
  和组合按键也可以映射到按键上
- **怪物锁定：** 轻点 Alt（R3）可让镜头持续对准怪物，目标图标旁会显示挂锁。此后从通常架势射出的
  子弹会瞄准怪物身体；你自己的瞄准、蹲射和各狩猎风格的招式仍由你控制。可将其关闭：**F1** → **控制** → **锁定**
- **用键盘输入：** 角色名，以及在集会所中按 **/** 输入聊天行，任务中也可使用
- **触屏：** 在带触屏的 PC 上，触摸屏幕时会显示手机的触屏控制（**控制** → **触屏控制**），
  并可用 **自定义按键与 HUD** 放置它们

#### 菜单与舒适性

- **游戏菜单中的鼠标操作，如同较新的作品：** 在道具箱、道具袋、暂停菜单、装备箱及
  其他列表中，以及在有人与你对话或游戏询问时，可指向并点击。左键为 A，右键为
  B，滚轮滚动列表并翻页，侧键也可翻页。见[控制](#controls)
- **WASD 可在游戏菜单中移动光标，** 在城镇中同样如此：道具箱、商店、任务柜台及其任务板
- **设置（F1）** 可用鼠标、键盘或手柄操作，支持英语或西班牙语。按 Esc、B 或在窗口
  外点击会关闭每个窗口
- **更快的饮用与进食：** 与手机上相同的两个可选作弊，默认关闭，位于 **F1** → **作弊**
- **你自己的作弊与模组：** 见[作弊与模组](#cheats-and-mods-1)
- 从模拟器或 Android 应用导入存档，也可导出带走：见[存档](#saves-1)
- 游戏窗口最小化时会停止，恢复时从原处继续（**F1** → **菜单选项** → **后台暂停**）

#### 自定义

- **移动 HUD：** **F1** → **显示** → **移动 HUD**，用鼠标拖动任意部分：时钟、生命与耐力、
  锋利度与各种量表、队伍、地图、目标镜头、道具栏和狩技。滚轮可改变某部分的大小，**隐藏** 可将其从屏幕上移除。键盘和手柄使用同一套 HUD。操作方法见
  [控制](#controls)
- 移动过的部分会停留在你放置的位置：聊天行、瞄准以及任务完成印章不再被送回原位，打开
  游戏菜单时也不会跳动。若某个部分会压在该菜单窗口上，它会隐藏，直到菜单关闭
- **在宽屏上，** **HUD 锚点**（**F1** → **显示**）会将 HUD 布置在中间的 16:9、21:9、32:9 区域或整个
  宽度上
- **组合按键：** 最多可自定义 6 个按钮，每个按钮同时按下多个键，例如 A+X，可映射到按键（**按键绑定**）或
  手柄按键（**控制** → **组合按键**）

#### 显示与性能

- 使用你屏幕的分辨率，默认无边框全屏，也可使用任意大小的窗口。**F11** 或 **Alt+Enter**
  在两者间切换。画面会立即采用窗口的形状，从 16:10 到超宽屏
- 最高 240 fps，或无限制。在任何帧率下，游戏都保持正常速度
- **3D 分辨率** 最低可到 25%，HUD 和文字始终保持清晰
- **低配模式** 和 **烤面包机** 适用于集成显卡和性能较弱的 PC
- **FSR 3.1、XeSS-SR 或 FSR 4** 用于重建较小的 3D 画面；MSAA 最高 8x，FXAA 和 **平滑渐变**
- **阴影**、**泛光与景深** 和 **混响**：各自独立的开关
- **绘制距离** 用于城镇与集会所中的角色，以及 **视野**
- **GPU：** 在配备两块显卡的 PC 上，选择游戏使用的显卡（默认使用独立显卡，如果有）
- **显示 FPS 与 PC 状态：** 帧率、GPU 温度；选择 **完整** 还会显示 GPU 与 CPU 的使用率
- 首次启动会在徽标播放期间准备游戏的所有着色器，因此第一次游玩时出现黑色的地方更少
- 游戏位于硬盘上时，启动会预读游戏代码，以减少卡顿

更多内容见[画面与帧率](#graphics-and-frame-rate)。

#### 使用手柄

- 连接后即可游玩。按 **F1**，或同时按 **+** 和 **-**，打开设置
- 按下右摇杆会锁定怪物
- **任意手柄：** 如果游戏无法正确识别你的手柄，请进入 **F1** → **控制** → **映射手柄**，依次按下每个
  按钮一次。映射会按该手柄型号保存
- 设置可按你的手柄样式显示按钮（**控制** → **按钮图标**）

#### Discord

如果同一台 PC 上打开了 Discord 应用，你的个人资料会显示你正在做什么：所在位置、正在狩猎的怪物、
地图与区域、同行猎人的数量、你的武器，以及猎人的名字和 HR。此功能默认开启。关闭方法：**F1** → **联机** → **Discord Rich Presence**。若要隐藏名字和 HR：**显示猎人名字和 HR**。游戏只会与本机上的 Discord 应用通信。

### <a id="what-you-need-1"></a>所需条件

- **Windows 10 或 11，** 64 位。
- **支持 Vulkan 1.2 的显卡，** 且驱动为最新：第 6 代 Core（2015 年）及之后的 Intel 集成显卡、
  NVIDIA GeForce GTX 600 或更新型号，或 AMD Radeon HD 7700、R7、R9 或更新型号。
- **支持 SSE4.2 的 64 位处理器：** Intel Core i3、i5、i7（2009 年及以后）或更新型号，2012 年及以后的 AMD FX、A 系列，或 Ryzen。较旧的
  处理器不支持，例如 Intel Core 2 或 2013 年前的 Atom、AMD Phenom II 或 Athlon II，以及 2011 年的 AMD A 系列和
  E 系列；游戏启动时会说明。
- **建议 8 GB 内存。** 在不打开其他程序的情况下，4 GB 应该可以运行，但加载会更慢，且尚未测试。
- **可用空间：** 游戏目录约 13 GB，工具工作期间至少再留 3 GB，程序和其着色器约需 0.5 GB。
- **你自己的游戏副本，** 已更新到 1.4.0 版本。

### <a id="setup-1"></a>安装设置

共三步，只需做一次。

#### 第 1 步：获取游戏文件

你需要自己游戏中的两个文件夹：`exefs` 和 `romfs`。它们必须包含 1.4.0 更新。

如果你的游戏副本位于 PC 上的 Ryujinx 模拟器中：

1. 确保游戏已应用 1.4.0 更新。
2. 右键点击游戏，打开 **Extract Data**，先提取 **ExeFS**，再提取 **RomFS**，放入同一个空文件夹。

将两者放在同一个文件夹中，例如 `C:\MHGU`：

```
MHGU
├─ exefs
└─ romfs
```

本项目不说明如何从主机中导出游戏，也不提供游戏文件、密钥或其链接。

#### <a id="step-2-create-the-game-code-1"></a>第 2 步：生成游戏代码

程序本身不包含游戏代码，因此你需要从自己的游戏副本生成。它在你的 PC 上运行，不会向任何地方发送数据。

1. 安装 [Python](https://www.python.org/downloads/)。勾选安装程序中的 **Add python.exe to PATH**。
2. 在本页面点击绿色的 **Code** 按钮，再点击 **Download ZIP**，然后解压。
3. 打开解压后的文件夹，再进入其中的 `tools` 文件夹。
4. 点击该窗口的地址栏，输入 `cmd` 并按 Enter。
5. 输入以下命令，将路径替换为你自己的文件夹，然后按 Enter：

   ```
   python build_game.py --pc C:\MHGU
   ```

首次运行时，它会下载 llvm-mingw，即 PC 版游戏的编译器（约 150 MB）。之后它会自行工作：在较快的 PC 上约 10
分钟，在只有 2 个核心的机器上最多约 1 小时。当它显示 **Done** 时，你的文件夹中会有两个新文件：

```
MHGU
├─ exefs
├─ romfs
├─ mhgugame.dll
└─ mhgugame.id
```

**这些文件由你的游戏生成：请自行保留，不要分享。**

你也玩 Android 版吗？省略 `--pc`：一次运行会同时生成两个平台的游戏代码，并额外生成 `libmhgugame.so` 和
`libmhgugame.id`。它还会下载 Google 的 Android 编译器（约 1.8 GB）。如果你之前生成过手机版，再次运行会
保留这些文件，只添加 PC 版。

#### 第 3 步：安装

没有安装程序：程序就是一个文件夹。

1. 从 [Releases](../../releases/latest) 下载 `MHGU-PC-<version>.zip`，并将其全部解压到你自己的文件夹中，
   例如 `C:\Games`（直接在 zip 内打开时，`MHGU.exe` 无法启动）。不要放在 Program Files：游戏会将
   设置、缓存和日志保存在自己的文件夹中，而 Windows 不允许它在那里写入。请保留 `MHGU.exe` 这个名称：游戏
   代码会按该名称查找程序。
2. 打开 `MHGU.exe`。Windows 可能会提示无法识别该程序，因为它没有签名：**更多信息** → **仍要运行**。如果
   启用了 Smart App Control，Windows 会阻止它：见[出现问题怎么办](#if-something-goes-wrong-1)。
3. 首次运行时，屏幕会要求选择游戏目录：点击 **选择文件夹**，选择你的 `MHGU` 文件夹。游戏会检查它，若有问题会准确告知缺少什么，然后启动。它会记住该文件夹。

如果 `MHGU.exe` 位于你的 `MHGU` 文件夹内，与 `exefs` 和 `romfs` 并列，游戏会自动找到它，无需询问。首次启动
会在徽标播放期间于后台准备游戏着色器；它们会在 `cache` 文件夹中占用约 340 MB。随后会有提示说明 **F1** 可打开设置。之后若要选择其他文件夹：**F1** → **菜单选项** → **游戏目录**；游戏
会从下次启动起使用它。

该 zip 包含一个文件夹，里面只有程序文件，不含任何游戏内容：

- `MHGU.exe`，以及它使用的库：`SDL3.dll`、`mhguffmpeg.dll`（游戏视频）和 `libxess.dll`（XeSS-SR）
- `gamelib_id.txt`：此版本所需的游戏代码 id。你文件夹中的 `mhgugame.id` 必须与之相同
- `pipelines.list`：首次启动时准备的图形状态
- `extras`：用于更快饮用与进食的可选作弊，首次启动时会以关闭状态复制到 `MHGU.exe` 旁的 `cheats` 文件夹
- `licenses`：法律声明与许可证，也可在 **F1** → **致谢与许可证** → **许可证** 中查看

- **游戏菜单中的鼠标：** 在道具箱、道具袋、暂停菜单、装备箱及其他列表中，以及
  在有人与你对话或游戏询问时，指针会显示并像较新作品那样工作：指向某一行
  或某个框即可选中（显示其详情），左键为 A（确认所指或所选项，并继续
  对话），右键为 B（返回；在菜单和对话中它不是 A，F 仍是 A），滚轮滚动列表并切换
  框的页面（在数量选择中增加或减少 1，在是/否问题中选择答案；大多数情况下
  也可以指向并点击；其他情况下按 F 确认），侧键翻页。在菜单和
  对话之外，鼠标仍像以前一样转动镜头。在这些菜单和对话中，左键是 A 而不是 X：如果菜单要求按 X，
  请按 R。关闭方法：**F1** → **控制** → **游戏菜单中的鼠标**。
- **手柄：** 连接后即可游玩；同时按 + 和 − 打开设置。如果游戏无法正确识别你的手柄：**控制** →
  **映射手柄**。

  `shots`，**F7** 尝试 MSAA 等级但不保存，**/** 在集会所中打开聊天（西班牙语键盘上为 **-**
  键；可在 **按键绑定** 中更改）。
- **HUD：** 打开 **F1** → **显示** → **移动 HUD**，用鼠标拖动任意部分：时钟、生命与
  耐力、锋利度与各种量表、队伍、地图、目标镜头、道具栏和狩技。将滚轮置于

### <a id="graphics-and-frame-rate"></a>画面与帧率

在集成显卡的笔记本上，或在 4K 屏幕上，请降低 **F1** → **显示** 中的 **3D 分辨率**（HUD 和
文字保持清晰），或在 **画面与音频** 中开启 **低配模式**：3D 画面会降到约 720 行（1080p 下为 66%，
1440p 下为 50%，4K 下为 33%），并且泛光、景深、MSAA 和 FSR 会关闭。其第三个选项 **烤面包机** 会降到约 540
行、30 fps，并关闭阴影和 FXAA。两者都需要重启游戏后生效。

**帧率上限**，位于 **画面与音频**，可从 30 到 240，或选择 **无限制**（默认 60）。无限制需要
关闭 **VSync**：开启 VSync 时，最高为显示器的刷新率。在无法稳定 60 的 PC 上，30 更平稳。同一处还有
**显示 FPS 与 PC 状态**：**基本** 显示帧率、帧时间、最长帧和 GPU 温度；**完整** 还会增加一行 GPU 信息（使用率、时钟、显存）和一行 CPU 信息。Windows 不允许程序读取 CPU
温度。

开启 **FSR** 后，该处的 **放大器** 一行还会提供 XeSS-SR。它需要 Intel Iris Xe 或 Arc 显卡，或支持 DP4a
的显卡，例如 AMD RX 6000 或 NVIDIA RTX 3000 及更新型号（在这些显卡上其开销高于 FSR 3.1），并且需要 Microsoft Visual C++
Redistributable（x64）。缺少这些条件时，游戏会使用 FSR 3.1，该行会说明原因。同一列表中的 **FSR 4** 面向 AMD
Radeon RX 9000 显卡：它尚未测试，且需要在 `MHGU.exe` 旁放置 AMD 自己的 `amd_fidelityfx_vk.dll`，该文件未包含在内。
请只从 AMD 获取，绝不要从其他网站下载。没有它时，会运行 FSR 3.1。FSR 本身也有开销：若要在性能较弱的 GPU 上
提升速度，应降低 3D 分辨率或改用低配模式。

在 **显示** 下：**窗口模式**（无边框、全屏或窗口化）、**屏幕分辨率**、**视野**、面向宽屏的 **HUD 锚点**，
以及 **填充屏幕**，它让游戏视频和菜单背景填满宽于 16:9 的屏幕，而不是在两侧显示黑边。在 **画面与音频** 下：**GPU**、**MSAA**、**FXAA**、**绘制距离**、**阴影**、
**泛光与景深**、**平滑渐变**、音量、**混响** 和 **后台静音**。

### <a id="saves-1"></a>存档

从 **F1** → **菜单选项**：

- **导入存档：** 选择存档的 `system` 文件。从 Ryujinx：右键点击游戏，选择 **Open User Save Directory**；从 yuzu：
  右键点击游戏，选择 **Open Save Data Location**；从手机：先在手机上导出（见
  [在 Android 与 PC 之间转移存档](#move-a-save-between-android-and-pc)）。此处的角色会被替换，游戏
  会带着该存档重启，被替换的存档会保留在 `%APPDATA%\MHGURecomp\save_backups`。
- **导出存档：** 先在游戏中保存，然后选择文件夹，其中会创建一个包含 `system` 和
  `system_backup` 的 `MHGU_save_...` 文件夹。若要带到模拟器，请备份其存档文件夹中的现有内容，然后将两个文件复制进去。
  若要带到手机，将 `system` 复制到手机，并在手机上使用 **导入存档**。

### <a id="cheats-and-mods-1"></a>作弊与模组

- **作弊：** Atmosphere 格式的 `.txt` 文件，适用于 1.4.0 版本（其构建 id 为 `FB08F1D20FD1204F`）。**F1** → **作弊** →
  **添加作弊**，然后选择文件。它们默认关闭：在该页面逐项开启并点击 **保存**。开启或关闭无需重启。
- **模组：** 包含 `romfs` 或 `exefs` 的模组文件夹，或该文件夹的 `.zip`。**F1** → **模组** → **添加模组**。然后
  在页面中排序并开启：当两个模组修改同一文件时，列表中靠下的优先。
- 它们会放入游戏目录的 `cheats` 和 `mods`，你也可以自行放置，游戏会重启以读取
  它们。每个作弊文件和每个模组都有各自的 **移除**：作弊文件的作弊会立即停止；游戏正在使用的模组
  会在重启后移除。
- 用于更快饮用与进食的可选作弊也在那里，默认关闭。
- 修改游戏代码的作弊与模组可以使用，但游戏的该部分会运行得更慢。在线使用作弊时，只有在
  集会所内所有人都同意的情况下才可以。

### <a id="multiplayer-1"></a>联机

本地游玩和通过互联网的集会所与手机版相同，使用相同代码和相同设置，位于 **F1** →
**联机**：见[本地游玩](#local-play)和[通过互联网](#over-the-internet)。在城镇中按 ZL（Tab）并选择
**连接**。

- **创建集会所** 用 X 确认：键盘上为 R。
- 首次创建集会所时，Windows 防火墙会询问是否允许 MHGU 使用网络。请允许，否则其他人无法发现或加入你的集会所。只有主机需要这样做。如果你选择了否：Windows 安全中心 → **防火墙和网络保护** → **允许应用通过防火墙**。
- 搜索会询问 PC 所在的每个网络。通过 VPN（例如 Tailscale 或 ZeroTier）时，也可以在 **搜索主机** 中输入主机的 IP
  并重启游戏。
- PC 与手机可以在同一集会所中游玩（双方均为 0.1.6 或更高版本）。
- 可调整的怪物 HP（**游戏玩法**，其中 **按任务覆盖** 下可设置单个任务的 HP）以及集会所中的村庄任务
  （**联机**）来自 MHGURecomp。

已在 PC 上测试：通过集会所服务器以及在同一 Wi-Fi 下加入手机的集会所。尚未测试：在 PC 上创建集会所（需要
防火墙授权）以及完成一次完整任务。

### <a id="update-to-a-new-version-1"></a>更新到新版本

1. 解压新版本，并将其文件覆盖到旧文件上。你的设置、所选文件夹和 HUD 布局会保留，
   存档无论如何都会保留。
2. 如果新版本需要新的游戏代码，游戏启动时会显示「This mhgugame.dll is from another version」。请用新版本的工具重新执行第 2 步
   （再次使用本页的 ZIP，或该版本发布页上的 **Source code (zip)**），然后再次打开游戏。

### <a id="uninstall-it-1"></a>卸载

- 删除程序文件夹，即包含 `MHGU.exe` 的那个。其设置、缓存、截图、日志和内置作弊也会一并删除。
- 你的存档会保留在 `%APPDATA%\MHGURecomp`。只有在希望彻底删除时才删除该文件夹，并请先备份。
- 你的游戏目录归你所有：可以留给手机版使用，也可以删除。你添加的作弊与模组就在其中。
- 工具会将下载的编译器保存在用户文件夹的 `.mhgu-tool` 中。如果不再生成游戏代码，可以删除它。如果缺少 lz4 Python 包，工具会安装它（`pip uninstall lz4` 可将其移除）；如果你为此安装了
  Python，Python 会保留。
- 不会安装其他内容：没有安装程序，游戏也不会在注册表中保存设置。如果你允许 MHGU
  通过 Windows 防火墙，该规则会一直保留，直到你在 Windows 安全中心中将其移除。

| 问题 | 处理方法 |
|---|---|
| `python` 无法识别 | 重新安装 Python，勾选 **Add python.exe to PATH**，并打开新的终端 |

| 「SDL3.dll was not found」 | 先将整个 zip 解压到文件夹：`MHGU.exe` 无法直接从 zip 内启动 |

| 「mhgugame.dll is missing」 | 下载内容不包含它：请执行[安装设置第 2 步](#step-2-create-the-game-code-1)（`python build_game.py --pc <your folder>`）并选择该文件夹 |
| 「This mhgugame.dll is from another version」 | 新的 PC 版本需要重新生成：用新下载的工具重复第 2 步 |
| 「This processor lacks instructions the game code needs」 | PC 版需要支持 SSE4.2 的处理器：见[所需条件](#what-you-need-1) |
| 「This program must be called MHGU.exe」 | 将其重命名为 `MHGU.exe` |
| 「This PC's graphics has no Vulkan driver」 | 从显卡厂商处安装最新驱动。最旧的显卡没有 Vulkan 驱动：见[所需条件](#what-you-need-1) |
| 「Windows ran out of memory」 | 关闭其他程序，或让 Windows 管理页面文件 |
| 每次启动都询问游戏目录 | Windows 不允许它在自己的文件夹中写入：请将其移出 Program Files |
| 启动时关闭，或窗口一直黑屏 | 更新显卡驱动 |
| 鼠标无法转动镜头 | 先点击窗口。Esc 释放鼠标 |
| **放大器** 一行显示正在使用 FSR 3.1 | 你选择的放大器无法在此 PC 上运行，该行的帮助会说明原因。对于 XeSS-SR，常见原因是缺少 Microsoft Visual C++ Redistributable（x64） |
| 运行缓慢 | 降低 **3D 分辨率** 或开启 **低配模式**；仍然缓慢则用 **烤面包机**。在双显卡笔记本上，检查 **GPU** 是否显示独立显卡 |

MHGU 的 Android 版免费，PC 版同样免费。唯一的官方下载渠道是 khorne-hub 提供的链接，首先是
本仓库的 [Releases](https://github.com/khorne-hub/gu-native/releases)。如果你从其他任何地方获得它、为它付费，或
你的副本带有广告，那就不是官方版本。在应用中，设置顶部 **保存** 旁的 GitHub 按钮会在浏览器中打开此页面，
旁边的 Discord 按钮会打开社区的 [Discord](https://discord.gg/sk5xEjEMwF)。

每个官方 APK 都用同一密钥签名。其证书的 SHA-256 指纹为：

```
D7:2F:6F:F1:55:E0:31:2C:9C:74:86:C5:30:64:60:38:E4:24:94:C0:AD:7C:D6:5F:4B:19:FF:5D:0F:32:B2:97
```

要检查 APK：`apksigner verify --print-certs MHGU-<version>.apk`（Android SDK build-tools）。使用另一
密钥签名的副本也无法覆盖安装到官方应用上。从 0.1.9 起，应用也会检查：使用另一密钥签名的副本会在启动时提示一次。

应用还会在有新版本时告知你。它每天最多一次向 GitHub 查询本仓库的最新发布
（不会发送其他内容，连手机型号也不会），并在下次启动时提供打开发布页的选项。它绝不会
自行下载或安装任何内容。齿轮按钮 → **菜单选项** → **检查更新** 可将其关闭。

PC 版没有此类签名：每个发布版本都会列出其 zip 的 SHA-256。要在 Windows 上校验，请在其文件夹中打开终端
并运行 `certutil -hashfile <file> SHA256`；结果必须与发布页列出的一致。
